# Rome Bike Mayhem

Web multiplayer prototype (10 players per room) with Node + WebSocket and a 2D platform style client.

## Run

1) Install deps:

```
npm install
```

2) Start server:

```
npm start
```

3) Open on mobile/desktop:

```
http://localhost:3000
```

## Notes

- Movement is arcade platform style with simple physics and platforms.
- Room caps at 10 players.
- WebSocket only; no persistence.
